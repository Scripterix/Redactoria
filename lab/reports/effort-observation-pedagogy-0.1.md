## What should not be optimized away

Evidence verification, exact-hash validation, Critic review, human approval and a
rendered check when presentation matters are quality costs, not waste.

## Evidence-bounded options

1. **NOW:** route Project Brain and evidence reads more narrowly; record only
   known artifact references in a Teaching Plan.
2. **NEXT:** observe whether repeated full reads recur across independent articles;
   then assess a small input index, not a compressor.
3. **LATER:** reconsider a manifest only after repeated lifecycle evidence proves
   it reduces operator work without hiding provenance.
4. **NOT WORTH IT now:** automatic context compression, cache/orchestration layer,
   new memory system, token pseudo-metrics, or an automatic Humanizer.

No implementation recommendation follows from unmeasured time.
