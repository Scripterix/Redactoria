# Markdown, calculator and API featured images — generation record

Date: 2026-10-16

## Scope and mode

Three independent illustrations were generated with the built-in ImageGen path.
`src/assets/dom-w-javascript.webp` was supplied as a style and proportion
reference, not an edit target. Each accepted source was an opaque 1672×941 PNG.
The sources were center-normalized without content edits to opaque sRGB WebP,
1600×900, quality 88.
