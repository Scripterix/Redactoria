# Critic 0.1

Independent runtime module: exact validated draft + approved research/addenda
+ optional actual example execution evidence → one grounded REVIEW → STOP.

Separate contracts, policies, stable prompt, validation, report and tests.
No Writer invocation, rewrite, filesystem, shell, new research or publication tools.
Manual CLI saves only LAB/reviews. Verdicts are PASS / REVISE / BLOCK.
Factual issues need exact draft locations and approved evidence; missing knowledge
is needs-research, not a new invented fact. Validation cannot prove semantic truth.
SOURCE_ALIGNMENT and UNSUPPORTED_CLAIMS apply the packet's Source Authority Ladder;
Stack Overflow may expose problems but never independently grounds a technical fact.
The pilot imports a distinct review in the same Codex session, not an independent
provider/model; functional role separation is explicit, not a claim of model diversity.
PASS hands off to human review and never approves publication.
