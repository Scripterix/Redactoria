# EDU article input — first programming languages

- **ROUTE:** `HUMAN_WRITTEN`
- **PERSONA:** EDU 0.1 — self-directed beginner
- **KNOWS:** can use a computer; recognizes numbers, a switch and a simple line of
  code; may have seen JavaScript or another modern language.
- **DOES_NOT_KNOW:** binary representation, machine instruction, stored program,
  assembler, compiler, fixed-form source or why programming languages were needed.
- **LEARNING_GOAL:** build a causal mental model from physical states through
  machine instructions and symbolic translation to FORTRAN and later languages.
- **LIKELY_CONFUSIONS:** a lamp performs the calculation; every early computer used
  the same switches; punch cards were binary in one universal format; FORTRAN was
  the only possible “first language”; a compiler needs an earlier compiler written
  in its own language.
- **PREREQUISITES:** none beyond everyday computer use and simple arithmetic.

## Pedagogical check

The dialogue repeatedly asks the learner to predict the missing layer before the
explanation arrives. It removes terminology gaps while preserving the work of
distinguishing data, instructions, hardware and translation. This matches
`docs/pedagogy-principle.md`: the article acts as a flashlight, not an autopilot.
No artificial exercise or complete historical taxonomy was added merely to satisfy
a template.
