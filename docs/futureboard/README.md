# Redactoria Futureboard

Futureboard is the project's think tank. It contains ideas, hypotheses,
experiments, alternative architectures, possible agents, business concepts, and
directions that may be worth exploring.

Futureboard is **not** the roadmap. An entry here is not an implementation
requirement and must not be built merely because it is documented.

```text
IDEA
  ↓
Futureboard
  ↓
discussion / experiment
  ↓
accepted?
  ├── NO → stays in Futureboard
  └── YES
        ↓
      ADR and/or Roadmap
```

Each idea should have a visible status. Promotion requires an explicit decision and
an update to the relevant ADR or roadmap entry.
